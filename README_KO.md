# EJU 인텔리전스 플랫폼 (EJU Score Tracker)

> 일본 유학시험(EJU, 日本留学試験) **종합과목**을 위한 데이터 분석 · AI 예측 플랫폼
> 스캔한 기출지(PDF/이미지)에서 출발해 → OCR → 지식 그래프 → 24년 출제 경향 분석 → 2026~2028 토픽 예측 → 설명 가능한 학습 플랜까지 한 번에 처리합니다.

이 문서는 영문 [`README.md`](./README.md)의 한국어 버전입니다. **이 문서에 적힌 모든 수치는 저장소 안의 실제 파일 또는 재현 가능한 스크립트에서 직접 검증한 값입니다.** (출처를 함께 표기)

---

## 1. 프로젝트 소개

EJU 종합과목(경제·역사·정치·지리·사회)은 24년치(2002~2025) 기출이 누적되어 있지만, 학생 입장에서 "무엇이 자주 나오는지 / 다음 시험에 무엇이 나올지 / 내 약점이 어디인지"를 정량적으로 파악하기 어렵습니다.

이 플랫폼은 그 과정을 데이터로 자동화합니다.

- **입력**: 기출 PDF/사진 또는 모의고사 점수
- **처리**: OCR → 5개 도메인 분류 → 지식 그래프 → 경향 분석 → 예측 엔진 → 약점 분석
- **출력**: 출제 경향 대시보드, 2026~2028 토픽 예측, 우선순위 학습 플랜, 설명 가능한 추천

데스크톱(Electron)과 웹(PWA) 양쪽에서 동작하며, **AI 코치는 100% 온디바이스로 실행**되어 외부 서버로 데이터를 보내지 않습니다.

## 4. 분석 방법론

### 4.1 데이터 파이프라인

```
기출 PDF/이미지
  → OCR 전처리(그레이스케일 → 히스토그램 스트레칭 → Sauvola 이진화)
  → Tesseract.js OCR (jpn+eng, PSM 6)
  → 5개 도메인 분류기 (가중 키워드 스코어링)
  → 중복 제거 (완전 중복 행 dedup: 1,310 → 1,121)
  → 지식 그래프 (선수 개념 연결)
  → 경향 엔진 (토픽·도메인·연도별 집계, 최신성 가중)
  → 예측 엔진 (베이지안 · 마르코프 · 추세 · Leave-Future-Out 백테스트)
```

### 4.2 출제 경향 분석

골드 스탠더드(검수 완료) 데이터를 토픽 단위로 집계합니다.

> **데이터 무결성 정비 (2026-06):** 원본 골드 스탠더드에는 완전히 동일한 중복 행 189개가 있었습니다. `DATA_AUDIT_REPORT.md`의 감사 결과에 따라 **완전 중복 행을 제거(1,310행 → 1,121문항)** 한 뒤 모든 통계·예측을 재생성했습니다. 재현 스크립트: `scripts/regenerate_analysis.mjs`.

- **분석 대상**: **1,121문항**(원본 1,310행 − 중복 189), 35개 토픽, 2002~2025년(24년)
  - 출처: `dataset/trend-analysis/trend_analysis_complete.json` (`total_questions_analyzed: 1121`, `total_topics_tracked: 35`, `analysis_period: "2002-2025"`)
- **도메인 비중** (종합영역 1,119문항 기준, 미분류 2 제외): 경제 **45.3%** · 정치 **18.8%** · 역사 **17.6%** · 지리 **15.7%** · 사회 **2.6%**
  - 출처: 골드 스탠더드 재집계 (경제 507 / 정치 210 / 역사 197 / 지리 176 / 사회 29)
- **최신성 가중**: 최근 출제일수록 가중치를 높여 현재 경향을 반영
- **성장률 정의**: `(최근 5년 출제수 − 이전 19년 출제수) / 이전 19년 출제수 × 100`

## 5. AI 예측 엔진

예측 엔진은 각 토픽에 대해 **3개의 실제 통계 모델 점수**(베이지안·마르코프·추세)에 모멘텀·최신성 보조 요소를 더해, 가중 합으로 다음 시험 출제 확률을 추정합니다. 모든 점수는 2002~2025 골드 스탠더드에서 직접 계산됩니다. (재현: `scripts/regenerate_analysis.mjs`)

### 5.1 점수 모델과 가중치

| 모델 | 가중치 | 정의 (실제 계산식) |
|:-----|:------:|:-----|
| **Bayesian** | 30% | 최신성 가중 Beta-Binomial 사후확률 `P(다음 시험 출제)`. Jeffreys 사전분포 `Beta(0.5,0.5)`, 최신성 반감기 8년 |
| **Markov** | 20% | 2상태(출제/미출제) 마르코프 체인의 전이확률. 라플라스 평활, 다년(2027+)은 현재 상태에서 `k-step` 전이 |
| **Trend** | 20% | 연도별 출제수의 OLS 회귀 기울기를 로지스틱으로 (0,1) 사상 |
| Momentum | 15% | 최근 3년 평균 vs 직전 2년 평균 출제 추세 |
| Recency | 15% | 마지막 출제연도와의 간격(gap) 기반 최신성 |

> 각 토픽 행에는 `bayes_score`, `markov_score`, `trend_score`, `trend_slope`와 보조 요소가 모두 기록되어 **대시보드의 "2026 예측 근거 상세" 표**에서 토픽별 점수 분해를 그대로 확인할 수 있습니다.
> 출처: `dataset/prediction/prediction_2026_2028.json` → `methodology.models`, `top_predictions[].bayes_score / markov_score / trend_score`

**다년 예측의 원리:** 2027·2028 확률은 마르코프 `k-step` 전이로 산출됩니다. 매년 반복 출제되던 토픽은 확률이 서서히 안정값으로 수렴하고, 오래 미출제된 토픽은 복귀 확률이 점차 상승합니다(예: 14년 미출제 `재정·조세정책`의 마르코프 점수 0.143 → 0.194 → 0.212).

### 5.2 검증된 성능 (실측 — 새 엔진 백테스트)

> ⚠️ 이전 README가 인용하던 F1 0.885는 **구(舊) 예측 엔진**의 수치입니다. 엔진을 베이지안·마르코프·추세 기반으로 교체했으므로, 아래는 **새 엔진을 직접 재백테스트**한 정직한 실측값입니다. (재현: `scripts/backtest_engine.mjs`, 결과: `dataset/prediction_accuracy_v2.json`)

- **Leave-Future-Out 백테스트 (2016~2025, 10개 폴드)** — 각 연도 Y에 대해 `Y-1년까지의 데이터만`으로 학습 후 Y년 출제 토픽 예측 (**데이터 누수 없음**)
  - 과제: 35개 표준 토픽 중 해당 연도에 출제될 토픽 분류 (확률 ≥ 0.5)
  - 평균 정밀도 / 재현율 / F1 = **0.831 / 0.762 / 0.779**
  - 최근 연도 예: 2023년 F1 **0.909**(TP 20 / FP 2 / FN 2), 2025년 F1 **0.780**(TP 16 / FP 3 / FN 6)

> ⚠️ **면책**: "이 예측은 과거 출제 빈도 분석에 기반하며 실제 시험 출제를 보장하지 않습니다." 확률은 의사결정을 돕는 신호이지 확정이 아닙니다.

## 10. 차트별 해설 — "이 그래프가 의미하는 것"

출제경향 대시보드의 모든 차트 아래에는 **설명 가능한 분석(Explainable Analysis)** 박스가 자동 생성되어, 핵심 발견사항 / 장기 추세 / 최근 5년 변화 / 수험생 시사점 4개 항목을 실제 수치로 서술합니다. 아래는 각 차트를 어떻게 읽는지에 대한 안내입니다.

### 📊 영역별 출제 비중 (원형 차트)
- **의미하는 것**: 24년간 5개 영역(경제·정치·역사·지리·사회)이 전체 출제에서 차지하는 비율.
- **읽는 법**: 경제 **45.3%**가 단연 최다이며, 경제+정치를 합치면 **64%** — 3문제 중 2문제 수준입니다.
- **활용**: 학습 시간이 부족하면 경제·정치를 먼저 다지는 것이 기대 점수 효율이 가장 높습니다.

### 📅 연도별 영역별 출제 추이 (누적 막대)
- **의미하는 것**: 각 연도(2002~2025)에 영역별로 몇 문항이 출제됐는지.
- **읽는 법**: 막대 하단(경제)이 매년 두껍고 상단(사회·역사)이 얇은 패턴이 반복됩니다. 한 해 평균 약 47문항.
- **활용**: 특정 연도에 몰린 토픽보다 매년 반복되는 핵심 토픽에 집중하는 편이 안정적입니다.

### 📋 전체 35개 출제 토픽 (빈도순 리스트)
- **의미하는 것**: 표준 토픽 35개를 24년 누적 출제 횟수 순으로 나열.
- **읽는 법**: 1위 `수요·공급과 시장균형`(201회), 2위 `세계대전`(112회). **상위 10개 토픽이 전체 출제의 약 68.6%**를 차지합니다.
- **활용**: 상위 10개만 확실히 잡아도 출제의 과반을 대비할 수 있습니다.

### 📈 최근 상승 / 📉 하락 토픽
- **의미하는 것**: `(최근 5년 − 이전 19년) / 이전 19년` 성장률 기준으로 뜨는 토픽과 식는 토픽.
- **읽는 법**: 상승 예) `사법·재판`(+600%), `지형·판구조`(+125%). 하락은 절대 출제수가 큰 베테랑 토픽이 최근 빈도가 줄어든 경우입니다.
- **활용**: 상승 토픽은 최신 경향 반영이 필수, 하락 토픽은 기본기 유지 수준으로.

### ⏰ 장기 미출제 토픽 (복귀 예상)
- **의미하는 것**: 과거에 자주 나왔지만 최근 오래 안 나온 토픽(gap ≥ 3년).
- **읽는 법**: `재정·조세정책`(14년), `러시아혁명·소련`(11년), `일본경제사`(8년).
- **활용**: 마르코프 모델상 복귀 확률이 매년 오르는 후보군 — 2순위 학습 대상입니다.

### 🔮 2026~2028 예측 + 예측 근거 상세 표
- **의미하는 것**: 각 토픽의 다음 시험 출제 확률과, 그 확률을 만든 **Bayesian / Markov / Trend** 점수 분해.
- **읽는 법**: 2026년 1위 `환율·국제수지` 80% (Bayes 0.96 · Markov 0.96 · Trend 0.34). 막대가 길수록 해당 모델이 출제를 강하게 지지한다는 뜻입니다. 현재 **확률 60% 이상 토픽은 14개**.
- **활용**: 60%+ 토픽을 1순위, 장기 미출제 복귀 후보를 2순위로 배치. **단, 예측은 과거 빈도 기반 신호이지 확정이 아닙니다.**
